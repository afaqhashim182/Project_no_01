About Me & Internship

I'm Afaq Hashim from Peshawar, Pakistan. Full-Stack Development Intern at Decode Labs Tech - Batch Sep 30 to Oct 30, 2026..

This is Project 1: The Responsive Architecture. Task was to build a fully responsive website using only semantic HTML5, CSS Design Tokens (#A5866F Mocha, #A0D4E0 Blue) and CSS Grid/Flexbox. No Bootstrap, no Tailwind.

What I Implemented:

Pillar 1 - Semantic (header/nav/main/section/article/footer)

Skills: HTML5 Semantic, CSS3 Grid, Flexbox, clamp(), WCAG (skip-link, focus-visible, Escape to close menu)
